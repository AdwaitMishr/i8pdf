# Sample input and output

So the system can be evaluated, and the demo video followed, without running
anything.

## Input

| What | Where | Size |
| --- | --- | --- |
| The six provided starter PDFs | [`../data/starter/`](../data/starter/) | 511 pages |
| Two synthetic probe notes | [`input/`](input/) (copies of [`../data/probe/`](../data/probe/)) | 1 page each |

The probe notes are **test fixtures, not source documents** — each says so on its
own first line. They are generated by `scripts/make_probe_pdf.py` and exist only
because the six official documents contain no cross-document contradiction that
survives the context checks. See Case 2 in `output/four-cases.md`.

## Output

Produced from the starter documents plus both probe notes:

| File | What it holds |
| --- | --- |
| `output/four-cases.md` | the four required cases, with full evidence and reasoning |
| `output/stats.json` | corpus totals, relationship counts, per-document rows |
| `output/facts-sample.json` | 40 facts with their evidence spans and highlight offsets |
| `output/relations-corroborates.json` | agreement, including cross-scale value bridges |
| `output/relations-contradicts.json` | conflicts with no available explanation |
| `output/relations-reconciled-by-context.json` | apparent conflicts, with the dimension that explains each |
| `output/relations-part-of.json` | component-inside-total pairs, with the sanity check |

Each relationship record carries `reasoning` in plain English, `differs_on`, and
both facts in full — including `evidence.text` and `evidence.value_offset`, the
character range of the number inside its own sentence.

## Regenerating

```bash
rm -f demo.db
python -m factlayer --db demo.db ingest data/starter
python -m factlayer --db demo.db ingest data/probe/probe-note-delhivery.pdf \
    --collection delhivery --subject "Delhivery"
python -m factlayer --db demo.db ingest data/probe/probe-note-india.pdf \
    --collection india-macroeconomy --subject "India"
python scripts/export_samples.py --db demo.db
```

Runs are reproducible: the same PDFs produce the same facts, relationships and
counts every time.
